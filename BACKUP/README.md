# BACKUP — BFAT ver.1

이 폴더는 **BFAT v2** 대규모 코드 수정에 앞서 보관한 **BFAT ver.1** 스냅샷입니다.

- **백업 시점**: UI 형태(색상, 요소 배치 등)를 유지한 채 v2 작업을 시작하기 직전 상태
- **복원**: 필요 시 `BFAT ver.1` 폴더 내용을 프로젝트 루트로 복사해 이전 상태로 되돌릴 수 있습니다.

백업에는 다음이 **포함**되어 있습니다:
- `backend/` (소스 코드, `__pycache__`·가상환경 제외)
- `frontend/` (소스 코드, `node_modules`·`dist` 제외)
- 루트 스크립트 및 설정 파일

`.env` 등 비밀 정보가 포함된 파일은 백업에 넣지 않았거나, 넣었다면 삭제 후 사용하세요.
